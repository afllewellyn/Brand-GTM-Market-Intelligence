# Architecture Decision Records

Short records of decisions that shaped this codebase, written so a future
reader — or a future architecture review — does not re-litigate ground
that has already been covered.

An ADR belongs here when the *reason* for a decision is load-bearing and
not recoverable from the code. "We chose X over Y because Z" is an ADR.
"This function does X" is a docstring.

Records are numbered in the order the decisions were made, never renumbered,
and never deleted. A decision that stops holding gets a new record that
supersedes the old one, and the old one is marked as superseded.

Domain vocabulary lives in [`CONTEXT.md`](../../CONTEXT.md), not here.
